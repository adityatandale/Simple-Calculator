# Simple-Calculator
# Calculator Application

A simple command-line calculator application built using Python.
This project performs basic arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division

---
Features -
* User-friendly menu
* Performs basic mathematical calculations
* Handles division by zero errors
* Simple and beginner-friendly Python project

Technologies Used -
* Python 3

Project Structure - 
```text
calculator/
│
├── calculator.py
└── README.md
```

## How to Run the Project

### 1. Install Python

Download and install Python from:

[Python Official Website](https://www.python.org?utm_source=chatgpt.com)


2. Clone the Repository
```bash
git clone https://github.com/your-username/calculator.git
```


3. Navigate to Project Folder
```bash
cd calculator
```

4. Run the Program
```bash
python calculator.py
```


Code Explanation -
The program uses:
* `print()` → to display output
* `input()` → to take user input
* `float()` → to convert input into numbers
* `if-elif-else` → for decision making
* Arithmetic operators (`+`, `-`, `*`, `/`) → to perform calculations
